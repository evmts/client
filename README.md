# Client

We will be building an execution client in the future. For now we are just experimenting though. None of the code you see here is production code, will be maintained, or should be used in production. The goal of this project right now is to just experiment with different client designs to learn more about the design space.

We are using rust as our language atm because it's currently the frontrunner for being the language we choose, but we are not committed to using it in future and may change.
